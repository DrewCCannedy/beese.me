# A Static Site for Beece
## Requirements
1. A static website hosted in github pages
2. Be designed for mobile first
3. Have 4 pages, index.html, lessons.html, contact.html, and production.html
4. Pages go in /pages other than index.html
5. Css goes in /css
6. Images go in /images
7. Use best practices
8. Use a pleasing design for a musician
9. Use bootstrap if needed

### Home Page Requirements
1. It should have an image at the top
2. It should have 5 rows
3. In the first row, an image to be provided later 
4. In the second row, the words "WHAT I DO:" 
5. In the third row, two columns, each with 3 rows. In the first row is a title, second row an image, third row a button. 
6. First column of the third row is "Lessons" then an image, then a button that says "Book Now" that links to the lessons page.
7. Second column of the third row is "Production" then an image, then a button that says "Let's talk" that links to the production page.
8. In the fourth row, it should be big font that says BEESE with a box around it
9. In the 5th row should be a button that says beese.me

### Production Page Requirements
1. It should have a title of "Production" at the top
2. Then "I record, mix, and master from my home studio
3. Then a wide photo
4. Then a button that says "Let's talk" that links to the contact page
5. Also a link back to the home page

### Lessons Page Requirements
1. It should have a title of "Lessons" at the top
2. Then "I like to play many instruments. I like to teach many, too."
3. Then two columns, one with "I teach: " followed by a list of guitar, bass, drums, banjo, ukelele, mandolin, & many more! all on new rows.
4. The next column would be an image
5. After all that a line that says "I also teach theory & production"
6. Then a button that says "Book A Lesson Now" that links to the contact page
7. Also a link back to the home page

### Contact Page Requirements
1. It should have a title that says "hey, send me a message:" 
2. And a form with Name, EMail, phone, subject, and body and send it as an email to me@gmail.com for now
3. Should have a link back to the home page
